# 1win Reels — прототип ставки на концовку

## Публикация на GitHub Pages
1. Загрузите в репозиторий всё содержимое папки: `index.html`, `sw.js`, папку `videos/`.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту прототип откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как устроена загрузка
- Страница лёгкая (~0,5 МБ), ролики лежат отдельно в `videos/`.
- Ленивая подгрузка: качаются только текущий и следующий ролик.
- `sw.js` кэширует ролики: при повторном заходе они берутся из кэша и не скачиваются заново.
- После замены роликов поменяйте `CACHE = 'reels-v1'` в `sw.js` на `reels-v2`, чтобы у всех обновился кэш.

## Устройства
- С компьютера — макет 393×852 целиком.
- С телефона — свои статус-бар и панель браузера, ролик подстраивается под высоту экрана.
